# Presentation guides

Use **Find_My_Professor_FOUR_PAGE_GUIDE.docx** for the latest presentation guide. It is verified as four pages and covers the project overview, technology stack, architecture, workflows, security, testing, demo steps, and judge questions.

**Find_My_Professor_TWO_PAGES_FINAL.docx** is the shorter two-page alternative.

Editable text is in `four-page-content.md` and `two-page-final.md`. The matching Python builders generate the Word files using `python-docx`. The older `Find_My_Professor_Presentation_Guide.docx` is a previous two-page version; `guide-content.md` preserves the original extended reference material.

Temporary page renders and machine-specific rendering helpers are excluded from Git.
